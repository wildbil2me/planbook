D · Proposed — ⌨ opens a dialog, the way it does on Attendance

Entering scores from the keyboard

One column at a time, and your hand never leaves the keyboard. Type a score, press Enter, and the caret drops to the next student in the same assignment.

↵
Next student, down the column. It stops at the last name.
⇥
Next assignment, across the row.
↑↓
Up or down the column.
←→
Across the row once the caret has run out of number — the end of the score for →, the start of it for ←. Inside a number they still move the caret.
L
Late. The score still counts in full.
M
Missing. Counts as zero.
X
Excused. Drops out of the grade.
C
Clear. The cell goes back to blank — score and mark together, in one press. Blank is ungraded, not zero.
⌫
Inside a number, one character. On an empty cell, takes its mark off.
N
Note on this cell. Enter or Esc puts you back in the cell; the note is already saved.
Esc
Closes this list. On the grid it does nothing.
The strip becomes a dialog, worn in Attendance’s own rows (.attendance-keys, .attendance-key-row, .attendance-key, shipped and unchanged) and the modal-form kind WO-1.77 ruled. Rows that wrap end the problem WO-3.24 measured: the strip’s rows are nowrap, so each had to be checked for spilling through its border at 390px, and the ← → row has been reworded twice to fit. In a dialog it says the whole thing.
C and N are rows here now — the owner, 2026-10-11 — and ⌫ is reworded to what it does on its own.
Does ? open it from the grid, as on Attendance? — Yes, the owner, 2026-10-11. A score cell is a text field asking for a decimal keypad, and ? is not a score, so it is free; WO-3.32’s Trap refuses only a key the grid already uses.
Is this dialog inside WO-3.58’s review? — No, the owner, 2026-10-11. That review rules where a dialog’s messages, notes and warnings sit against its buttons, and this one has none of them: a read-only list and a ✕, like its twin on Attendance, which is outside 3.58 too. WO-3.58’s Not in scope names it, and neither row waits on the other.
The hint’s Escape does nothing here because there is no dialog to close stays true of the grid and is reworded to say so — the last row of the dialog already does.
