One screen, one primary. Add your first class stays the only primary button, and the other two doors sit under a hairline as the secondary way forward. It is one empty state saying one thing: here is how to fill this year. Nothing new is added to the stack, and it goes away when the empty state does, which is exactly when the year stops being untouched, so the rule for hiding it is free. The cost is that it is quieter: a teacher on her second device has to read past the first button to find it. The buttons are real 44px buttons, not text links.
