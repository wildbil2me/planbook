Cold-start traps

The ones that bite hardest after a gap

The injected CLAUDE.md can be stale

What a session is handed is a snapshot from when it started. Read the file before calling any of it out of date — especially the status paragraph, which changes most days.

Never a second scope

drive.file and nothing else, ever. Not spreadsheets, not a mail scope — outreach is mailto:. Adding a scope also resets Google's clock.

The whole point is that there is no backend

No Apps Script, no functions/ directory, no client secret. If you find yourself copying a secret into a file, something has gone architecturally wrong.

Sync is not a backup

Drive holds one live copy that sync will happily overwrite. The downloadable JSON backup stays mandatory, and no feature that writes student data lands ahead of it.

Check the code before rescheduling

A work order's premise may already be satisfied by something that landed since it was written. WO-8.4 cost a commit and a correction. Cheap to check, expensive to miss.

Mutation tests clobber unstaged edits

The git checkout after a mutation reverts your own unstaged work in that file. Stage first.
