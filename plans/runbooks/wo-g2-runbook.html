Entry sitting

Five classes in under 20 minutes

Pick one real assignment that all five classes have: the same task, or one assignment per class from the same week. Enter it for real.

  1. Start the stopwatch when you open the first class's grid, not when you sit down.
  2. Enter every student's score in all five classes. Mark missing, late and excused as you normally would. The app never infers them from a due date.
  3. Stop the stopwatch when the fifth class's last score is in.

The bar is 20 minutes for all five. If it takes longer, the useful record is where the time went: the grid, the keyboard, looking up who was absent, or the SIS in the other window.

Entry sitting

The printout's order against the SIS

Straight after box 4, while the scores are fresh:

  1. On one class's gradebook, tap 🖨 Grade sheet in the header strip. This is the term as one sheet, in the order the SIS is typed in. Print it, or keep it open on screen.
  2. Open the SIS grade-entry screen for the same class and assignment.
  3. Re-key the scores from the sheet into the SIS, top to bottom, without skipping around.

The question is whether the sheet's order of students is the SIS's order, so the re-key is a straight run down both lists. One student out of place is a failure worth recording, because that is how a score lands on the wrong child.

Real grades

The letter scale is yours

The app ships with this scale:

AA-B+BB-C+CC-D+DD-F
93908783807773706763600

There is no separate rounding rule. If the school or the SIS treats 89.5 as an A-, the band's minimum is 89.5, not 90. That is the boundary case this box is about: a student at 89.6 gets a B+ from the app and an A- from the SIS, and a guardian finds out in November.

The scale is in Classes & terms → Letter grades → Letter scale. The dialog opens on the year's bands, and the row under These bands are for switches to one class. A class can have its own bands, which replace the year's for that class only, so this check is per class. A class you gave its own bands once and then forgot about is exactly what this box should catch.

  1. Find out what the SIS does at a boundary: round, truncate, or neither. The quickest test is a real student near a line, or the district's grading policy.
  2. Compare every band above with the scale you actually use. If they differ, edit the year's bands in the dialog.
  3. Step through all five classes under These bands are for. Note whether each uses the year's bands or its own. If it has its own, check those too.
  4. Find one real student within half a point of a boundary, and check that the app's letter matches the SIS's.

Real grades

One real class, computed by hand

Choose a class where, this term:

  • at least one student has a score marked missing,
  • at least one student has a score marked excused,
  • at least one category has no assignments yet, so its weight redistributes.

You mark these yourself and the app never infers them, so if no class has all three yet, this box waits for a week that does. Don't mark a real score just to close this box.

For each of the three students:

  1. Write each category's points earned over points possible. missing counts as zero earned, full points possible. excused counts as neither: it leaves the category entirely.
  2. Turn each category into a percentage.
  3. Drop the empty category and scale the remaining weights up to 100. With weights 50/30/20 and the 20 empty, that's 50/80 and 30/80.
  4. Weighted sum, then percentage, then letter from box 3's scale.
  5. Compare with the app.

Real grades ~30 min

The backup drill, with real grades

The drill Ship 1 ran on 2026-08-08, run again now that a wipe would cost grades as well as attendance. One thing is new: both devices sync through Google Drive. A wipe also erases the device's sync bookmark and its opt-in. The steps allow for that, including one conflict message you should expect to see.

What the wipe does to sync, so none of it looks like a failure

After the wipe the device is signed out and the header has no sync button. Opting in was stored on the device, and the wipe erased it.

The empty screen offers two ways back: Open from Google Drive and Restore a backup file. Use Restore a backup file. This drill tests the file. Opening from Drive would also bring the year back, but it would test Drive, and Drive is not a backup.

The first sync after the restore shows a message that begins:

Both copies of … had changed since the last sync, so Planbook kept both and merged nothing.

That is correct. The device lost its record of the last sync, so it can't tell which copy is newer, and it keeps both. The restored year becomes the live one, and My Drive gets one extra conflict file, named in the message. You can delete that file once your figures have matched.

Laptop
  1. Tap the header's sync button on both devices, one after the other, so the laptop, the iPad and Drive hold the same year. Don't edit on the iPad until the laptop half is done.
  2. Download a fresh backup on the laptop, not the one from the top of this page.
  3. Note a few figures to check afterwards: one class's grade for three students, one class's assignment count, one attendance percentage.
  4. Wipe the site's storage. In Edge: DevTools (F12 works in the app window) → Application → Clear site data. This removes the service worker too, so the drill also tests a reinstall.
  5. Reload. The home screen should read "No classes yet." and show the two buttons. Tap Restore a backup file and choose the file from step 2.
  6. Check the figures from step 3. Then check every class, every student, every score, and every missing and excused mark.
  7. Reconnect: About → Connect Google Drive. Tap sync and read the conflict message.
iPad

The Ship 1 drill required the iPad, and the iPad is where storage is actually at risk. An installed web app on the iPad has no DevTools, so the wipe is deleting the app and installing it again.

  1. Tap sync on the iPad. It should download the laptop's restored year. Check that one of the laptop's figures is right.
  2. Download a fresh backup on the iPad, and note where Files saved it. The file stays in Files after the app is deleted.
  3. Force-quit Planbook from the app switcher. Then press and hold its Home Screen icon → Delete. Deleting the icon deletes the app's storage too. You've seen this every time you've deleted the app: the year comes back only from a backup or a sync, never by itself.
  4. In Safari, open https://planbook.hwgteach.com/ → Share → Add to Home Screen, and launch Planbook from the new icon.
  5. The home screen should read "No classes yet." This is a quick confirmation and shouldn't fail. If your classes are still there, something new has happened: record it and stop the iPad half.
  6. Tap Restore a backup file, pick the file from step 2, and check the same figures.
  7. Reconnect from About, and sync. Expect the same conflict message, and a second extra file in Drive.

If a restore fails or a figure is wrong, don't reconnect that device

Sync would upload the wrong year over the good copy in Drive. Leave the device as it is, write down what you saw, and bring it home. The backup from the top of this page is still untouched.

The fifteen hand-computed cases

Each case uses its own small scale (A ≥ 90, B ≥ 80, C ≥ 70, F ≥ 0) unless it says otherwise, and percentages are unrounded. Work each one on paper and tick it here.
